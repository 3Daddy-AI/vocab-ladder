# Vocab Ladder

大人のリスキリング向けの英単語・熟語アプリです。ビジネス英語の単語80個と熟語50個を収録しています。

- 練習は4種類：4択クイズ／カードめくり／スペル入力／発音練習
- 正解すると経験値がたまり、レベルと称号が上がります
- 忘れかけたころに復習の順番が回ってくる覚え方（間隔反復）を取り入れています
- 記録は使っている端末のブラウザの中だけに保存します（サーバーには送りません）
- 発音練習はブラウザの音声の聞き取り機能を使います（Chrome・Edge・Safari）

HTMLファイル1つで動きます。見た目の決まりごとは DESIGN.md にあります。
